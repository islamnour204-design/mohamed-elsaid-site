Edge AI

Proofs of concept on Intel AMX

I designed and delivered several customer proofs of concept on edge AI using Intel AMX, validating infrastructure strategies with measurable improvements.

On AMX-capable Xeon processors, each core carries tile registers and a matrix multiply unit. The core multiplies two tiles and adds the product into a third, so the CPU itself can accelerate supported inference workloads.

Research

A decade modelling what migration actually costs

Doctorate in IT Systems Engineering at the Hasso-Plattner Institute under Professor Christoph Meinel. The thesis uses machine learning to model and predict the overhead of live migration: moving a running virtual machine from one server to another without switching it off.

  1. Copy all memoryThe machine keeps running on host A while its memory pages travel to host B.
  2. Copy what changedPages the machine wrote during the first pass go again.
  3. Repeat, smallerEach round sends fewer pages, until the remainder is small.
  4. Pause and hand overA brief stop while the last pages and the processor state move.
  5. Running on host BThe same machine resumes on the new server.
